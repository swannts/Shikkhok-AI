# Shikkhok AI

An AI-powered education platform.

## Repository Structure

```
shikkhok-ai/
├── apps/                    # Application frontends (mobile, web, admin, teacher-portal)
├── services/                # Backend microservices/APIs (api, ai-gateway, worker, realtime)
├── packages/                # Shared internal libraries & components
├── ai/                      # AI prompts, evaluations, routing, guardrails, retrieval
├── curriculum/              # Curriculum schemas, ingestion scripts, seed data
├── data/                    # Database migrations, seeds, fixtures
├── infra/                   # Infrastructure configuration (docker, terraform, k8s)
├── docs/                    # Architectural & product documentation
├── scripts/                 # Utility scripts
└── tests/                   # Integration, E2E, performance, security tests
```
